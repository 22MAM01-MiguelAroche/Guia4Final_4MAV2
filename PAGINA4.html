Comceptos Basicos

  • Dominio:

    uso de un servidor web Domino para alojar páginas HTML.

  • sub dominio

    • se refiere a una parte de un dominio principal que se utiliza para organizar y separar secciones o funcionalidades de un sitio web.

  • URL

    • se refiere a la dirección de un recurso en la web, como una página web, una imagen o un archivo.

  • DNS

    • el término DNS se refiere al Sistema de Nombres de Dominio (Domain Name System), que es el "director telefónico" de Internet.

  • Hosting

    • El "hosting" se refiere al servicio de alojamiento web que permite que tu sitio web, creado con HTML y otros lenguajes web, esté disponible en internet para que los usuarios puedan acceder a él.

  • FTP

    • En HTML, el término FTP se refiere al Protocolo de Transferencia de Archivos.

  • HTTP

    • En HTML, el término HTTP se refiere al Hypertext Transfer Protocol, que es un protocolo de comunicación utilizado para transferir datos en la web, especialmente entre navegadores y servidores web.

  • HTTPS

    • En HTML, el término HTTPS se refiere al protocolo de transferencia de hipertexto seguro.

  • W3C

    • En HTML, el término W3C se refiere al World Wide Web Consortium, una organización internacional que desarrolla estándares y recomendaciones para la World Wide Web.

  • UTF-8

    • En HTML, el término UTF-8 se refiere a un estándar de codificación de caracteres que permite representar la mayoría de los caracteres Unicode, incluyendo letras, números, símbolos y emojis, en una página web.

  • HTML5 y su estructura

    • EHTML5 (HyperText Markup Language 5) es la quinta y última versión principal del lenguaje de marcado que define la estructura y el contenido de una página web. Su estructura básica incluye etiquetas, atributos y contenido de texto.
